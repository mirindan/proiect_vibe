# Agent Instructions

## Project goal

This repo is a Python demo project for controlled AI-agent development.

## Coding rules

- Keep code simple and readable.
- Do not change public function names unless asked.
- Prefer small, reviewable edits.

## Validation

- Run tests with: `python -m pytest`
- Explain any failing test before changing code.

## Permissions

Allowed without approval:

- Read files in this repo.
- Propose code changes.
- Edit files after explaining the plan.

Ask before doing:

- Installing packages.
- Deleting or renaming files.
- Running long commands.
- Changing test expectations.

Never do:

- Read `.env` or secrets.
- Push to remote.
- Disable tests to make output look correct.
